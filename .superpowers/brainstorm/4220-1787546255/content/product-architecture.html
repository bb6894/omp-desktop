恢复与错误规则

  • 重启后从 Host 恢复项目、任务和运行状态；Renderer 的缓存永远不是事实来源。
  • Host 或 Runtime 失败时保留任务，显示固定错误、诊断入口和“重新启动任务”，不清空时间线。
  • 审批超时、会话切换或旧响应均 fail-closed；任何错误都不回显凭据或完整环境。
  • 第一轮右侧“终端”只展示任务命令输出，不嵌入任意交互式 shell。
